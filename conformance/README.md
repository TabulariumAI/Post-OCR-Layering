# Post-OCR Layering conformance examples

[`post-ocr-layering-v1.0.json`](post-ocr-layering-v1.0.json) contains informative, machine-readable examples for specification version 1.0. The normative requirements remain in [Post-OCR-Layering-Spec.md](../Post-OCR-Layering-Spec.md).

Coordinates use page units. Source spans use zero-based, half-open intervals `[start, end)`. Each case provides words, lines, paragraph source intervals, applicable parameters, and expected structural output.

The vector format is an interchange format for conformance testing. It is not a required implementation API.

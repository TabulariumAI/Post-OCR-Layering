# Post-OCR Layering

An open specification for deterministic reconstruction of document structure from OCR text and geometry.

**Published version:** 1.0 (2026-11-17)

## Specification

See [Post-OCR-Layering-Spec.md](Post-OCR-Layering-Spec.md) for the model, inputs, decision logic, evaluation framework, worked example, and audit requirements.

The specification is licensed under Apache License 2.0; see [LICENSE](LICENSE). It describes the mathematical framework. Recognition pipelines, deployment configurations, and calibrated parameter values are outside the scope of this repository unless separately published here.

## Conformance

Machine-readable examples are provided in [conformance](conformance/README.md). They are informative test vectors for checking implementations against the normative predicates and decision order.

## Versions and citation

Published versions are immutable and identified by Git tags. Changes to normative behavior require a new version and a corresponding [changelog](CHANGELOG.md) entry.

Citation metadata is provided in [CITATION.cff](CITATION.cff).

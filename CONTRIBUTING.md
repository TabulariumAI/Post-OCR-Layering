# Contributing

Contributions to the Post-OCR Layering specification are welcome.

- Open an issue to identify the affected section and the proposed correction or clarification.
- Submit a focused pull request with the change and any necessary updates to equations, definitions, or worked examples.
- Check that notation and cross-references remain consistent across the specification.
- Update the specification version, `CHANGELOG.md`, and applicable conformance vectors when normative behavior changes.
- Run `python scripts/validate_repository.py` before submitting the pull request.
- Do not submit confidential information or material you are not authorized to publish.

By submitting a contribution, you agree that it is provided under the repository's Apache License 2.0.

Every commit must include a Developer Certificate of Origin sign-off:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Use `git commit -s` to add it. The sign-off certifies that you have the right to submit the contribution under the repository license. See the [Developer Certificate of Origin 1.1](https://developercertificate.org/).
